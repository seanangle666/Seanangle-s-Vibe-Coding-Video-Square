# Video Maker Pro - 重構版

## 項目結構

這個版本的應用程式已被重構為模塊化架構，提高了可維護性和可擴展性。

```
Desktop/
├── index.html          # 主 HTML 文件（簡潔的標記）
├── styles.css          # 集中式樣式表
├── js/
│   ├── state.js        # 全局應用程式狀態管理
│   ├── ui.js           # UI 元素初始化和事件綁定
│   ├── audio.js        # 音頻處理邏輯（解碼、播放、分析）
│   ├── rendering.js    # 光譜和畫布渲染邏輯
│   ├── recording.js    # 影片錄製和導出邏輯
│   └── app.js          # 主應用程式入口點和動畫循環
└── README.md           # 此文件
```

## 重構的優點

### 1. **文件分離**
   - HTML、CSS 和 JavaScript 現在分別存儲在獨立文件中
   - 提高了代碼的可讀性和可維護性
   - 便於版本控制和協作開發

### 2. **模塊化架構**
   - 每個 JavaScript 文件負責特定功能域
   - **state.js**: 集中管理應用程式的所有狀態
   - **ui.js**: 處理所有 DOM 操作和事件綁定
   - **audio.js**: 音頻相關功能（解碼、播放、分析）
   - **rendering.js**: 視覺渲染（光譜、影片畫布）
   - **recording.js**: 錄製和導出邏輯
   - **app.js**: 協調各個模塊，驅動應用程式主循環

### 3. **改進的代碼組織**
   - 更清晰的職責分離
   - 減少全局污染（大多數功能已導出到 `window` 對象）
   - 便於單元測試和調試

### 4. **易於擴展**
   - 可以輕鬆添加新功能而不影響現有代碼
   - 模塊之間通過明確的接口進行通信
   - 社區或團隊成員可以獨立開發不同的模塊

## 功能特性

### 影像處理
- 上傳自定義前景和背景圖像
- 實時預覽縮放效果
- 支持 9:16、16:9 和 1:1 比例

### 文字編輯
- 獨立的頂部和底部文字層
- 顏色和字體大小自定義
- 垂直位置調整
- 支持自定義字體上傳

### 音頻集成
- 上傳 MP3、WAV 等音頻文件
- 音頻頻率分析和視覺化
- 支持兩種動畫模式：
  - **BPM 模式**: 基於節拍進行縮放
  - **音頻反應模式**: 根據音頻頻率實時響應

### 影片錄製
- 實時預覽播放
- 高質量影片導出（WebM 格式）
- 錄製進度計時器
- 淡入淡出效果支持

## 使用方法

### 基本流程

1. **加載資源**
   - 上傳或選擇前景和背景圖像
   - 加載音頻文件
   - （可選）上傳自定義字體

2. **設置文本和動畫**
   - 編輯頂部和底部的標題/副標題
   - 選擇顏色和字體大小
   - 調整文本垂直位置

3. **配置動畫**
   - 選擇動畫模式（BPM 或音頻反應）
   - 調整動畫強度
   - 設置音頻開始時間和時長

4. **預覽和錄製**
   - 點擊"預覽播放"檢查結果
   - 點擊"錄製影片"生成最終視頻
   - 視頻將自動下載

## 技術棧

- **前端框架**: 純 JavaScript（無依賴）
- **樣式框架**: Tailwind CSS（通過 CDN）
- **圖標庫**: Font Awesome 6.4.0
- **音頻處理**: Web Audio API
- **影片錄製**: MediaRecorder API
- **字體加載**: FontFace API

## 瀏覽器支持

- Chrome/Edge 90+
- Firefox 95+
- Safari 15+

## 性能最佳實踐

- 使用 `will-change` 優化動畫性能
- 有效的畫布繪製（僅更新必要的部分）
- 驗證 DOM 元素存在以避免錯誤
- 使用 `requestAnimationFrame` 實現流暢動畫
